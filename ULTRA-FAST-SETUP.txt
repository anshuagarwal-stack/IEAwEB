IEA ULTRA-FAST MEMBER PAGES
===========================

What changed
------------
1. One Apps Script request now returns the Overview, Attendance and Membership data together.
2. The browser stores that bundle securely against the member's session token.
3. Clicking Overview, Attendance or Membership shows saved data immediately.
4. Data refreshes in the background after 90 seconds.
5. Google Sheets are read only once per API request instead of repeatedly.
6. Attendance no longer starts two separate server requests.
7. Existing admin panel, quick attendance, payments and enquiries are preserved.
